Resumen general

Datos guardados en este navegador — se actualizan solos a medida que usas los módulos. La cuota de cada residente es confidencial y no se muestra aquí.

Respaldo de datos

Los datos viven solo en este navegador (localStorage). Si se borra el caché o se cambia de equipo, se pierden para siempre — descarga un respaldo con frecuencia.
